# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this website
or its infrastructure, please report it responsibly.

**Email:** security@nimishanakkala.dev
**security.txt:** https://nimishanakkala.dev/.well-known/security.txt

Kindly do NOT open a public GitHub issue for security vulnerabilities.

## Response Timeline

- Acknowledgment: within 48 hours
- Assessment: within 7 days
- Fix: depends on severity

Thank you for helping keep this project secure.
